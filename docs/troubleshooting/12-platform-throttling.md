# 场景 12：平台限流

## 快速解决（≤3 步）

> 1. **调整码率至平台上限**：抖音 ≤6000、淘宝 ≤4000、视频号 ≤6000 kbps，在 OBS `设置 → 输出` 修改比特率。
> 2. **检查推流资质**：确认账号粉丝数与认证满足平台开播要求。
> 3. **联系平台客服**：核查是否触发风控规则，提交申诉解除限制。

若以上 3 步未解决，再阅读下方完整判定流程。

## 现象描述

推流成功但观众端画质明显低于 OBS 设置值，或平台在无明显技术问题时强制断流。

## 判定步骤

```
推流成功但画质被压缩 / 平台断流
│
├─ 步骤 1：推流码率是否超过平台上限？
│   查看 OBS 输出码率与平台限制对比
│   └─ 超出 → 修复动作 A（降低码率）
│
├─ 步骤 2：账号是否满足推流资质？
│   检查粉丝数、实名认证、开播权限
│   └─ 不满足 → 修复动作 B（完善账号资质）
│
└─ 步骤 3：是否触发平台风控？
    频繁开关播、异常时段推流等
    └─ 疑似触发 → 修复动作 C（联系客服申诉）
```

## 修复动作

### 动作 A：调整码率至平台限制内

| 平台 | 最大码率 | 推荐码率 | 备注 |
|------|---------|---------|------|
| 抖音 | 6000 kbps | 4000-6000 kbps | 粉丝 <1000 可能限制更低 |
| 淘宝 | 4000 kbps | 2500-4000 kbps | |
| 视频号 | 6000 kbps | 4000-6000 kbps | |
| Bilibili | 6000 kbps | 4000-6000 kbps | 大航海主播可更高 |

在 OBS 中：`设置 → 输出 → 视频码率`，填入平台允许的最大值。

### 动作 B：完善账号推流资质

各平台开播门槛：

| 平台 | 粉丝要求 | 其他要求 |
|------|---------|---------|
| 抖音 | ≥200 有效粉丝 | 实名认证 |
| 视频号 | ≥100 粉丝 | 实名认证 |
| 淘宝 | 商家入驻 | 店铺认证 |

不满足时：先达到粉丝门槛，完成平台要求的认证流程。

### 动作 C：联系平台客服申诉

常见触发风控的行为：
- 频繁开关播（短时间内 >5 次）
- 异常时段推流（凌晨 2-6 点）
- 内容违规历史导致限流

申诉路径：平台 App → 设置 → 帮助与反馈 → 提交申诉。

## 验证方法

1. 降低码率后推流 1 分钟，观众端确认画质恢复正常。
2. 推流持续 10 分钟以上无被强制断流。
3. 在平台后台确认直播状态为"正常"，无违规提示。
