# 场景 04：音画不同步

## 快速解决（≤3 步）

> 1. **设置音频同步偏移**：混音器 → 右键音频源 → 高级音频设置，声音超前则填正值（如 +200ms）。
> 2. **降低编码延迟**：编码预设改为 `veryfast`，关闭 B 帧（`bframes=0`）。
> 3. **避免无线音频设备**：改用 USB/3.5mm 麦克风，蓝牙耳机延迟通常 150-300ms 难以补偿。

若以上 3 步未解决，再阅读下方完整判定流程。

## 现象描述

直播中声音与画面出现明显延迟或错位：声音超前于画面，或画面超前于声音，两者偏差通常 ≥ 200ms，观众明显感知。

## 判定步骤

```
音画不同步
│
├─ 步骤 1：确认延迟方向（声音超前 or 画面超前）
│   播放一段有人说话的内容，观察口型与声音
│   └─ 声音超前画面 → 修复动作 A（增加音频延迟）
│   └─ 画面超前声音 → 修复动作 B（增加视频延迟 或 降低编码延迟）
│
├─ 步骤 2：检查是否由编码延迟引起
│   OBS → 查看 → 统计 → 查看"渲染延迟"和"编码延迟"
│   └─ 编码延迟 > 50ms → 修复动作 C（优化编码参数）
│
└─ 步骤 3：检查音频设备驱动延迟
    不同麦克风/声卡驱动延迟不同
    └─ 使用蓝牙麦克风或 USB 声卡 → 修复动作 A（手动补偿）
```

## 修复动作

### 动作 A：音频来源增加延迟补偿

当声音超前于画面时，为音频添加延迟：

1. 在 OBS 混音器中，右键对应音频来源（如麦克风）→ `高级音频设置`。
2. 找到 **"同步偏移（毫秒）"** 字段，填入正值（如 `200`）。
3. 实时调整直到音画对齐（可配合录制测试）。

```
混音器 → 右键音频来源 → 高级音频设置 → 同步偏移：+200 ms
```

### 动作 B：视频来源增加延迟（或降低编码延迟）

当画面超前声音时：

方法 1 — 为视频来源增加延迟（使用 OBS 插件 `obs-move-transition` 或滤镜）：

```
来源 → 右键 → 滤镜 → 添加"视频延迟（异步）" → 设置毫秒数
```

方法 2 — 减少编码延迟：`设置 → 输出 → 编码器预设` 改为 `zerolatency`（仅 x264）。

### 动作 C：优化编码参数减少延迟

```
设置 → 输出 → 输出模式：高级
  编码器：x264
  关键帧间隔：2
  CPU 使用预设：veryfast 或 superfast
  Profile：baseline
  调整：zerolatency
```

## 验证方法

1. 用手机录制一小段直播画面（拍摄屏幕），回放检查口型与声音是否对齐。
2. 或在 OBS 中录制一段本地视频，用 VLC 播放并检查同步情况。
3. 偏差应控制在人耳不可察觉范围（< 80ms）。
