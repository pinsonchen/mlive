# 场景 11：推流中断自动重连失败

## 快速解决（≤3 步）

> 1. **启用自动重连**：OBS → 设置 → 高级，勾选"自动重新连接"，重试延迟 5 秒、最多 20 次。
> 2. **平台断流超时**：若平台显示"直播已结束"，到平台重新开播并更新 OBS 推流地址。
> 3. **排查根本断流原因**：用 `ping` 监测网关丢包，必要时更换网络或联系 ISP。

若以上 3 步未解决，再阅读下方完整判定流程。

## 现象描述

网络短暂中断后 OBS 未能自动重新连接，或重连后平台显示"直播已结束"无法继续推流。

## 判定步骤

```
断流后 OBS 未自动恢复推流
│
├─ 步骤 1：确认 OBS 是否开启自动重连
│   OBS → 设置 → 高级 → "自动重新连接"
│   └─ 未勾选 → 修复动作 A
│
├─ 步骤 2：重连后平台是否显示"直播已结束"
│   查看平台直播间状态
│   └─ 是 → 修复动作 B（平台断流超时）
│
└─ 步骤 3：OBS 持续重连但均失败
    检查网络是否恢复、推流地址是否仍有效
    └─ 网络周期性中断 → 修复动作 C（排查根本原因）
```

## 修复动作

### 动作 A：启用自动重连

OBS → 设置 → 高级 → 勾选"自动重新连接"：

- 重试延迟：5 秒
- 最大重试次数：20 次

```
设置 → 高级 → 自动重新连接
  ☑ 启用自动重新连接
  重试延迟(秒)：5
  最大重试次数：20
```

### 动作 B：处理平台断流超时

部分平台断流超过 30-60 秒会自动关闭直播间：

1. 登录平台后台，重新开启直播。
2. 获取新的推流地址和密钥。
3. 在 OBS 中更新推流地址后重新推流。

| 平台 | 断流超时 | 处理方式 |
|------|---------|---------|
| 视频号 | ~30 秒 | 需重新开播、地址会变 |
| 抖音 | ~60 秒 | 需重新开播 |
| Bilibili | ~90 秒 | 可自动续推 |

### 动作 C：排查根本断流原因

```bash
# 持续监测网关丢包
ping -i 1 192.168.1.1 | tee ~/ping_log.txt

# 查看是否有周期性中断模式
# 常见原因：路由器过热、ISP 不稳定、WiFi 信号衰减
```

排查方向：
- 路由器过热 → 增加散热或更换路由器
- ISP 上行不稳定 → 联系运营商报修
- WiFi 信号弱 → 改用有线连接

## 验证方法

1. OBS 设置 → 高级，确认"自动重新连接"已勾选且参数合理。
2. 手动拔网线 5 秒再插入，观察 OBS 是否在设定延迟后自动重连。
3. 重连成功后确认平台直播间画面正常恢复。
