# 场景 03：黑屏

## 现象描述

推流已连接（OBS 状态栏绿灯），但观众收到的画面全黑，或平台直播间显示黑屏。OBS 本地预览可能正常也可能同样黑屏。

## 判定步骤

```
观众/平台看到黑屏
│
├─ 步骤 1：检查 OBS 预览是否也黑屏
│   查看 OBS 主窗口预览区域
│   └─ 预览也黑屏 → 修复动作 A（场景/来源配置问题）
│
├─ 步骤 2：OBS 预览正常，但推流黑屏
│   设置 → 输出 → 确认编码器选择
│   └─ 使用硬件编码（NVENC/AMF）→ 修复动作 B（切换软件编码）
│
└─ 步骤 3：检查显卡多显示器输出设置
    Windows 设置 → 显示 → 核查主副屏配置
    └─ OBS 捕获副屏/独显而输出主屏 → 修复动作 C（指定 GPU）
```

## 修复动作

### 动作 A：修复场景/来源配置

1. 在 OBS 场景列表中点击当前使用的场景，确认来源列表中的项目**前方勾选框已勾选**（眼睛图标显示）。
2. 右键来源 → `属性`，检查捕获目标是否正确（窗口标题、显示器编号）。
3. 如使用"显示器采集"，确认选中了有内容的显示器：

```
来源 → 显示器采集 → 属性 → 显示器：选择 "显示器 1（主屏）"
```

### 动作 B：切换到软件编码器

```
OBS → 设置 → 输出 → 编码器：
  将 NVENC H.264 / AMD AMF 改为 x264（软件编码）
```

若切换后预览恢复，说明 GPU 编码器与显卡驱动存在冲突，更新显卡驱动后可再次尝试硬件编码。

```bash
# Windows：通过 winget 更新 NVIDIA 驱动
winget upgrade NVIDIA.GeForceExperience

# macOS：系统设置 → 软件更新
```

### 动作 C：指定 OBS 使用独立显卡（Windows）

右键 `OBS Studio.exe` → `使用图形处理器运行` → 选择独立显卡（NVIDIA/AMD）。

或通过 NVIDIA 控制面板：`管理 3D 设置 → 程序设置 → OBS Studio → 首选 GPU`。

## 验证方法

1. 在 OBS 中对当前推流截图：`工具 → 截图`，检查截图是否有画面内容。
2. 平台观察端刷新直播间页面，画面应正常显示。
3. 检查 OBS 日志（`帮助 → 日志文件 → 当前日志`）无 GPU/编码器错误。
