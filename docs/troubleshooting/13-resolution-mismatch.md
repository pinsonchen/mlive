# 场景 13：分辨率不匹配

## 快速解决（≤3 步）

> 1. **设置正确画布**：竖屏 1080×1920，横屏 1920×1080，输出分辨率与画布保持一致。
> 2. **适配来源**：OBS 来源右键 → 变换 → "适配屏幕"，避免手动拉伸。
> 3. **匹配平台要求**：在平台开播设置中选择匹配的画质档位（码率 4000-6000 kbps）。

若以上 3 步未解决，再阅读下方完整判定流程。

## 现象描述

平台直播画面出现黑边、拉伸变形或裁切不完整，与 OBS 预览中看到的画面不一致。

## 判定步骤

```
平台画面出现黑边 / 拉伸 / 裁切
│
├─ 步骤 1：平台是否要求竖屏(9:16)推流？
│   检查平台开播设置中的画面方向
│   ├─ 是 → OBS 画布是否为竖屏？
│   │   └─ 否 → 修复动作 A（设置竖屏画布）
│   └─ 否（横屏 16:9）→ 步骤 2
│
├─ 步骤 2：来源是否正确填充画布？
│   检查 OBS 预览中来源是否有黑边
│   └─ 有空隙 → 修复动作 B（适配来源）
│
└─ 步骤 3：输出分辨率与画布是否一致？
    设置 → 视频 → 对比基础/输出分辨率
    └─ 不一致 → 修复动作 C（同步分辨率）
```

## 修复动作

### 动作 A：设置竖屏画布

OBS → 设置 → 视频：

```
基础（画布）分辨率：1080x1920
输出（缩放）分辨率：1080x1920
常用 FPS 值：30
```

若设备性能有限，可降为 720×1280。

### 动作 B：适配来源到画布

1. 在场景中选中来源（如"显示器捕获"）。
2. 右键 → 变换 → **适配屏幕**。
3. 若来源比例与画布不同，右键 → 变换 → **拉伸到屏幕**（会变形）或**居中到屏幕**（会有黑边）。

推荐做法：确保来源原始比例与画布比例一致，避免强制拉伸。

### 动作 C：同步输出分辨率

OBS → 设置 → 视频：

| 场景 | 基础分辨率 | 输出分辨率 | 码率建议 |
|------|-----------|-----------|---------|
| 竖屏直播 | 1080×1920 | 1080×1920 | 4000-6000 kbps |
| 横屏直播 | 1920×1080 | 1920×1080 | 4000-6000 kbps |
| 低性能设备 | 1280×720 | 1280×720 | 2500-4000 kbps |

确保"输出分辨率"与"基础分辨率"相同，避免缩放引入的模糊或比例问题。

## 验证方法

1. OBS 预览中画面无黑边、无拉伸变形。
2. 推流后用手机观看直播间，确认画面比例正确、无裁切。
3. 切换不同来源（窗口/游戏/摄像头），确认均正确适配画布。
