# 场景 05：RTMP 鉴权失败

## 现象描述

推流连接建立后立即断开，OBS 日志或状态栏显示：

- `HTTP 401 Unauthorized`
- `HTTP 403 Forbidden`
- `Authentication failed`
- 推流在几秒内自动停止

## 判定步骤

```
推流立即断开，日志含 401/403
│
├─ 步骤 1：核查推流密钥是否过期
│   登录平台后台 → 直播设置 → 推流密钥
│   └─ 密钥已过期或被重置 → 修复动作 A（重新获取密钥）
│
├─ 步骤 2：检查推流地址与密钥是否匹配
│   部分平台密钥与节点绑定
│   └─ 密钥来自 A 节点但推向 B 节点 → 修复动作 B（对齐节点与密钥）
│
└─ 步骤 3：确认账号状态
    检查平台是否有封禁、违规警告或实名认证缺失
    └─ 账号受限 → 修复动作 C（联系平台客服）
```

## 修复动作

### 动作 A：重新获取并填写推流密钥

**Bilibili**：

1. 登录 [直播中心](https://link.bilibili.com/p/center/index) → `我的直播间 → 开播设置`。
2. 点击"刷新推流码"（若已过期）。
3. 复制新的推流地址和推流码。

**抖音**：

1. 登录抖音直播后台 → `开播 → 电脑推流`。
2. 复制推流地址和推流码。

在 OBS 中更新：`设置 → 推流 → 推流码（Stream Key）`，粘贴最新密钥。

### 动作 B：对齐推流节点与密钥

```
# 推流地址示例（Bilibili）
服务器：rtmp://live-push.bilivideo.com/live-bvc/
推流码：?streamname=live_<uid>&key=<token>&schedule=rtmp&pflag=1

注意：推流码中的 key 参数与服务器域名绑定，勿混用不同节点的密钥
```

### 动作 C：检查账号直播权限

```bash
# 用 curl 测试鉴权（替换为真实地址和密钥）
curl -I "rtmp://live-push.bilivideo.com/live-bvc/?streamname=live_xxx&key=yyy"
# 若返回 HTTP/1.1 403，确认账号权限问题
```

联系平台客服时提供：OBS 日志文件（`帮助 → 日志文件 → 上传当前日志`），附上日志链接。

## 验证方法

1. 更新密钥后点击"开始推流"，OBS 状态栏绿灯亮起且保持稳定。
2. 登录平台直播后台，确认"直播状态"显示"直播中"。
3. 保持推流 60 秒，确认不会自动断开。
