# 场景 09：虚拟摄像头未被识别

## 快速解决（≤3 步）

> 1. **启动虚拟摄像头**：OBS 主界面右下角点击"启动虚拟摄像头"（按钮变为"停止"即激活）。
> 2. **重装 OBS 驱动**：在 OBS 安装目录运行 `installer/OBS-VirtualCam2-Installer.exe`，macOS 需在"系统设置 → 隐私与安全性"允许扩展。
> 3. **重启目标应用**：先启动 OBS 虚拟摄像头，再重启 Zoom/腾讯会议等，让其重新枚举摄像头。

若以上 3 步未解决，再阅读下方完整判定流程。

## 现象描述

启用 OBS 虚拟摄像头后，目标应用（如 Zoom、腾讯会议、钉钉、浏览器）的摄像头列表中找不到"OBS Virtual Camera"选项，或选择后显示黑屏。

## 判定步骤

```
目标应用找不到 OBS 虚拟摄像头
│
├─ 步骤 1：确认 OBS 虚拟摄像头已启动
│   OBS 主界面 → "启动虚拟摄像头"按钮是否已点击（变为"停止虚拟摄像头"）
│   └─ 未启动 → 点击启动，修复动作 A
│
├─ 步骤 2：目标应用未检测到驱动
│   检查 OBS 虚拟摄像头驱动是否正确安装
│   └─ 驱动未安装 → 修复动作 B（重新安装驱动）
│
└─ 步骤 3：目标应用权限或刷新问题
    部分应用需要在启动 OBS 虚拟摄像头后重启才能识别
    └─ 重启目标应用后识别 → 修复动作 C（调整启动顺序）
```

## 修复动作

### 动作 A：启动虚拟摄像头

```
OBS 主界面右下角控制栏 → 点击"启动虚拟摄像头"
  按钮变为"停止虚拟摄像头"即表示已激活
```

macOS 额外步骤：首次使用需授权系统扩展：

```
系统设置 → 隐私与安全性 → 安全性 → 允许"OBS Studio"扩展
重启 OBS 后再次启动虚拟摄像头
```

### 动作 B：重新安装虚拟摄像头驱动

**Windows**：

```
OBS → 工具 → 虚拟摄像头 → 安装虚拟摄像头
（若菜单中没有此选项，从 OBS 官网下载安装程序，选择"修复"）
```

**macOS**（安装 macOS 虚拟摄像头插件）：

```bash
# 使用 Homebrew 安装 OBS macOS 虚拟摄像头
brew install obs

# 或下载 OBS 官方 .pkg 安装包，重新运行安装程序
# 安装完成后：系统设置 → 隐私与安全性 → 允许扩展
```

**Linux**：

```bash
# 安装 v4l2loopback（虚拟摄像头内核模块）
sudo apt install v4l2loopback-dkms
sudo modprobe v4l2loopback

# 启动 OBS 后再启动虚拟摄像头
```

### 动作 C：调整应用启动顺序

正确顺序：**先启动 OBS 并激活虚拟摄像头，再打开目标应用**。

若目标应用已打开：

1. 完全退出目标应用（确认进程已终止）。
2. 在 OBS 中确认虚拟摄像头已启动。
3. 重新打开目标应用，在摄像头设置中选择"OBS Virtual Camera"。

## 验证方法

1. 在目标应用摄像头列表中选择"OBS Virtual Camera"，画面应显示 OBS 当前场景内容。
2. 用 Windows 相机应用或 macOS Photo Booth 测试：打开后选择 OBS 虚拟摄像头，确认显示 OBS 画面。
3. 在 Zoom 测试会议中确认视频预览正常。
