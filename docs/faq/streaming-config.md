# 推流配置常见问题

## FAQ-001: OBS推流后平台显示"未开播"

**问题**：OBS已经开始推流，但直播平台显示"未开播"或观众看不到画面。

**症状**：
- OBS状态栏显示"正在推流"且帧数正常
- 平台直播间仍显示"未开播"状态
- 观众反馈看不到画面

**原因**：
- 推流地址或推流密钥填写错误（多余空格、缺少字符）
- 平台端未点击"开始直播"按钮
- 淘宝直播未执行"暂停"步骤
- 推流地址已过期（视频号每次开播地址不同）

**解决步骤**：
1. 检查OBS中填写的推流地址和密钥，确保无多余空格
2. 确认平台端已创建直播间并点击开始
3. 淘宝直播：开始→等待10秒→暂停→再使用OBS推流
4. 视频号：每次开播前从视频号助手重新获取推流地址
5. 尝试停止推流后重新开始

**相关链接**：[多平台同步开播操作文档](../../多平台同步开播操作文档.md)

## FAQ-002: Multi RTMP插件添加推流目标后无法连接

**问题**：在Multi RTMP插件中添加了推流目标，点击开始后连接失败。

**症状**：
- 插件中显示红色"连接失败"或"断开"状态
- 错误提示"无法连接到服务器"
- 主推流正常但Multi RTMP推流失败

**原因**：
- RTMP地址格式不正确（缺少rtmp://前缀）
- 推流密钥未单独填入密钥字段
- 防火墙或杀毒软件阻止了连接
- 平台推流服务器暂时不可用

**解决步骤**：
1. 确认RTMP地址以 `rtmp://` 开头
2. 将推流地址和推流密钥分别填入对应字段（不要合并）
3. 检查防火墙设置，允许OBS的网络访问
4. 暂时关闭杀毒软件测试是否为其拦截
5. 在浏览器中确认平台直播间状态正常
6. 等待几分钟后重试（排除平台临时故障）

**相关链接**：[OBS Multi RTMP 插件](https://github.com/sorayuki/obs-multi-rtmp)

## FAQ-003: 推流画面卡顿或掉帧

**问题**：直播画面出现卡顿、掉帧、马赛克等现象。

**症状**：
- OBS右下角显示"丢帧"或帧数波动
- 观众反馈画面卡顿或模糊
- CPU使用率过高

**原因**：
- 码率设置过高，超出上行带宽
- CPU负载过大（编码器选择不当）
- 同时推多个平台导致带宽不足
- 网络不稳定（使用WiFi或高峰期）

**解决步骤**：
1. 降低码率：多平台推流建议不超过2500kbps
2. 切换编码器：优先使用硬件编码（NVENC/AMF）
3. 降低输出分辨率：从1080p降到720p
4. 使用有线网络代替WiFi
5. 关闭后台占用带宽的程序（下载、云同步等）
6. 在OBS设置中降低帧率（从60fps改为30fps）

**相关链接**：[网络优化指南](network.md)

## FAQ-004: 淘宝直播推流时必须先"暂停"是怎么回事

**问题**：淘宝直播使用OBS推流时，不执行"暂停"步骤就无法成功推流。

**症状**：
- 直接使用推流码推流，OBS提示连接失败
- 推流成功但淘宝后台不显示画面
- 推流码复制后无法使用

**原因**：
淘宝直播的推流机制要求在"暂停"状态下才能接受外部OBS推流。这是平台的技术限制。

**解决步骤**：
1. 在淘宝直播中控台创建直播间
2. 点击【开始直播】
3. 等待10秒，让系统生成推流码
4. 点击【暂停直播】
5. 此时复制推流地址和推流码到OBS
6. 在OBS中开始推流
7. 确认OBS推流成功后，回到淘宝中控台点击【继续直播】

**相关链接**：[淘宝直播操作文档](../../多平台同步开播操作文档.md)
