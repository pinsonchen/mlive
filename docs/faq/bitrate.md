# 码率相关常见问题

## FAQ-017: 多平台推流码率应该怎么设置

**问题**：同时推多个平台时，不知道码率设置为多少合适。

**症状**：
- 设置过高导致部分平台卡顿
- 设置过低导致画质模糊
- 不同平台要求不同不知如何兼顾

**原因**：
各平台对码率上限有不同限制，需要取各平台限制的最低值来保证所有平台正常。

**解决步骤**：
1. 各平台码率限制参考：
   - 淘宝直播：最高2500kbps
   - 小红书：推荐3000-4000kbps
   - 视频号：推荐2000-3000kbps
2. 多平台同推建议：设置在2000-2500kbps（取所有平台的最低上限）
3. 配合分辨率调整：
   - 2500kbps → 720p 30fps（推荐）
   - 4000kbps → 1080p 30fps（仅单平台）
4. 音频码率建议：128kbps（AAC格式）
5. 总带宽计算：(视频码率 + 音频码率) × 平台数 × 1.5 = 所需上行带宽

## FAQ-018: 码率设置正确但画质仍然模糊

**问题**：码率已设置到平台上限，但直播画质仍然不清晰。

**症状**：
- 画面整体模糊，尤其运动场景
- 文字和细节看不清
- 对比预览画面，推流画面质量明显下降

**原因**：
- 画布分辨率和输出分辨率不匹配
- 编码器预设选择不当
- 缩放滤镜选择了低质量算法
- 平台二次转码降低了画质

**解决步骤**：
1. 检查分辨率设置：
   - 设置 → 视频 → 画布分辨率：设为显示器原始分辨率
   - 输出分辨率：设为720p(1280×720)或1080p(1920×1080)
2. 缩放滤镜选择"Lanczos"（最高质量）
3. 编码器设置：
   - NVENC：预设选择"质量"或"最大质量"
   - x264：预设选择"medium"或更慢
4. 在码率允许范围内适当提高（但不超过平台限制）
5. 减少画面运动量（游戏直播可能需要更高码率）

**相关链接**：[OBS设置](obs.md)

## FAQ-019: 淘宝直播码率超过2500kbps会怎样

**问题**：不小心将码率设置超过了淘宝直播的2500kbps限制。

**症状**：
- 推流可能被平台强制降码率
- 画面出现异常卡顿
- 可能被平台警告或断流

**原因**：
淘宝直播2026年更新后严格限制推流码率上限为2500kbps，超出部分会被服务器端处理。

**解决步骤**：
1. 立即将OBS输出码率调整到2500kbps或以下
2. 推荐设置：2000-2500kbps之间
3. 如果使用Multi RTMP插件，可以为淘宝单独设置较低码率
4. 音频码率控制在128kbps
5. 配合720p分辨率，2500kbps可以获得不错的画质
6. 如果画质要求高，建议使用淘宝手机直播（无码率限制）

**相关链接**：[推流配置](streaming-config.md)
