# 鉴权与权限常见问题

## FAQ-013: 淘宝直播OBS推流权限无法开通

**问题**：在淘宝直播中找不到OBS推流入口或提示权限不足。

**症状**：
- 中控台没有"推流地址"选项
- 提示"暂无权限使用此功能"
- 只能使用手机直播，无法使用电脑推流

**原因**：
- 粉丝数未达到门槛（达人需1000+粉丝）
- 未完成淘宝直播入驻认证
- 账号类型不符合要求
- 保证金未缴纳

**解决步骤**：
1. 确认账号类型和门槛要求：
   - 达人账号：1000+粉丝 或 发布≥5条优质内容（质量分≥20）
   - 商家账号：微淘粉丝≥40,000 + 一钻以上
2. 完成淘宝直播入驻：淘宝直播APP → 主播中心 → 开通
3. 缴纳保证金：个人5000元，企业可免缴
4. 如果条件不满足，暂时使用手机直播方案或虚拟摄像头方案
5. 持续创作内容积累粉丝，达到门槛后再申请

**相关链接**：[平台政策](platform-policy.md)

## FAQ-014: 视频号推流地址获取失败

**问题**：在视频号助手中无法获取推流地址，或获取后无法使用。

**症状**：
- 视频号助手页面没有"推流地址"选项
- 获取到的地址复制到OBS后无法连接
- 提示"未满足推流条件"

**原因**：
- 粉丝未达1000人（OBS推流门槛）
- 未通过实名认证
- 推流地址已过期（每次开播重新生成）
- 浏览器缓存导致页面显示异常

**解决步骤**：
1. 确认满足条件：1000+粉丝 + 实名认证
2. 访问视频号助手（channels.weixin.qq.com）
3. 创建新的直播间
4. 在推流设置中获取最新的推流地址和密钥
5. 注意：地址每次开播都会变更，不能复用旧地址
6. 如果粉丝不足，可先使用PC微信直播（200粉丝或注册7天即可）

**相关链接**：[视频号助手](https://channels.weixin.qq.com)

## FAQ-015: 小红书直播权限和条件不明确

**问题**：不清楚小红书开通直播/OBS推流需要什么条件。

**症状**：
- 小红书APP中找不到开播入口
- 提示"暂不满足开播条件"
- 网上信息不一致（500粉/1000粉/5000粉说法不同）

**原因**：
小红书直播门槛经常调整，且不同账号质量、类型可能有不同要求。

**解决步骤**：
1. 手机直播基础条件：
   - 注册满6个月
   - 实名认证
   - 近3个月发布原创笔记≥10篇
2. OBS推流条件（以APP内显示为准）：
   - 粉丝500-1000+（平台动态调整）
   - 可能需要创作者认证
3. 开播路径：我 → 菜单(☰) → 创作中心 → 开始直播
4. 如果条件不满足：
   - 先用手机直播积累经验
   - 持续发布优质笔记增粉
   - 关注APP内的具体提示

**相关链接**：[平台政策](platform-policy.md)

## FAQ-016: 抖音直播权限与"有效粉丝"问题

**问题**：抖音提示粉丝数不满足开播条件，但实际粉丝数已超过要求。

**症状**：
- 粉丝数显示超过200但仍无法开播
- 提示"有效粉丝不足"
- 不理解"有效粉丝"和普通粉丝的区别

**原因**：
抖音2025年12月实施"有效粉丝"新标准，刷粉、互关等方式获得的粉丝不计入。

**解决步骤**：
1. 了解"有效粉丝"标准：
   - 互相关注的粉丝不算
   - 刷粉获得的不算
   - 需要真实互动（点赞、评论、转发）的活跃粉丝
2. 查看有效粉丝数：创作者服务中心 → 数据概览
3. 提升有效粉丝的方法：
   - 发布优质原创内容
   - 保持更新频率
   - 积极与粉丝互动
   - 参加平台活动增加曝光
4. 达到200有效粉丝后即可开通手机直播

**相关链接**：[平台政策](platform-policy.md)
