# OBS相关常见问题

## FAQ-009: OBS虚拟摄像头黑屏

**问题**：启动OBS虚拟摄像头后，其他软件（直播伴侣等）中显示黑屏。

**症状**：
- 直播伴侣选择"OBS Virtual Camera"后画面全黑
- OBS预览正常但虚拟摄像头输出无画面
- macOS用户在其他软件中看不到OBS虚拟摄像头选项

**原因**：
- OBS虚拟摄像头未正确启动
- OBS场景中未添加任何视频来源
- macOS权限未授予
- OBS版本过旧不支持虚拟摄像头

**解决步骤**：
1. 确认已启动虚拟摄像头：OBS菜单 → 工具 → 虚拟摄像头 → 启动
2. 确保当前场景中有视频来源（摄像头、窗口采集等）
3. macOS用户：系统偏好设置 → 安全性与隐私 → 摄像头 → 允许OBS
4. 重启OBS后重新启动虚拟摄像头
5. 在目标软件中重新选择摄像头来源
6. 更新OBS至最新版本（30.0+内置虚拟摄像头）

**相关链接**：[OBS官网](https://obsproject.com)

## FAQ-010: Multi RTMP插件安装后找不到

**问题**：已下载并安装Multi RTMP插件，但OBS中找不到相关选项。

**症状**：
- OBS工具菜单中没有"Multiple Output"或"Multi RTMP"选项
- 侧面板没有出现多路推流面板
- 安装过程未报错但插件不生效

**原因**：
- 插件版本与OBS版本不兼容
- 插件文件放置在错误目录
- OBS安装后未重启
- 下载了错误的操作系统版本

**解决步骤**：
1. 确认OBS版本：帮助 → 关于OBS，记录版本号
2. 对照版本兼容表选择正确插件版本：
   - OBS 32.x → 插件 v0.7.3.1
   - OBS 31.x → 插件 v0.6.0.1
   - OBS 30.x → 插件 v0.5.x
3. 完全关闭OBS（检查任务管理器确保进程已结束）
4. 重新安装插件（推荐使用.exe安装程序）
5. 重启OBS，检查工具菜单或侧面板

**相关链接**：[Multi RTMP插件下载](https://github.com/sorayuki/obs-multi-rtmp/releases)

## FAQ-011: OBS录制/推流时CPU占用过高

**问题**：开始推流后CPU占用率飙升，电脑卡顿，直播画面受影响。

**症状**：
- CPU使用率持续90%以上
- OBS提示"编码过载"
- 电脑风扇狂转，其他程序卡顿
- 推流画面掉帧严重

**原因**：
- 使用了软件编码器（x264）且编码预设过慢
- 输出分辨率或帧率设置过高
- 同时运行了过多占用资源的程序
- 未利用显卡硬件编码

**解决步骤**：
1. 切换编码器：设置 → 输出 → 编码器 → 选择硬件编码
   - NVIDIA显卡：选择"NVENC H.264"
   - AMD显卡：选择"AMF H.264"
   - Intel核显：选择"QSV H.264"
2. 如必须使用x264，将预设改为"veryfast"或"ultrafast"
3. 降低输出分辨率（1080p → 720p）
4. 降低帧率（60fps → 30fps）
5. 关闭不必要的后台程序
6. 多平台推流时，确认Multi RTMP使用相同编码设置

**相关链接**：[码率设置指南](bitrate.md)

## FAQ-012: OBS场景和来源丢失

**问题**：打开OBS后发现之前配置好的场景和来源全部消失。

**症状**：
- 场景列表为空或只有默认场景
- 来源列表为空
- 之前的配置文件似乎丢失

**原因**：
- OBS配置文件被意外删除或损坏
- 使用了便携版OBS且目录被移动
- Windows更新后权限变更
- 切换了OBS的配置集

**解决步骤**：
1. 检查是否切换了配置集：菜单 → 配置集 → 确认选中正确配置
2. 检查场景集：菜单 → 场景集 → 看是否有之前保存的场景
3. 备份路径：
   - Windows：`%APPDATA%\obs-studio\basic\scenes\`
   - macOS：`~/Library/Application Support/obs-studio/basic/scenes/`
4. 如果配置文件存在但OBS未加载，尝试手动导入
5. 日后建议定期导出场景集作为备份

**相关链接**：[OBS官方文档](https://obsproject.com/wiki/)
