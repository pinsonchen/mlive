# 平台政策常见问题

## FAQ-020: 抖音还能用OBS直接推流吗

**问题**：想在抖音使用OBS推流，但不确定是否还支持。

**症状**：
- 找不到抖音RTMP推流地址入口
- 网上搜到的推流教程已过时
- 使用第三方工具推流后被警告

**原因**：
抖音于2023年起正式取消了OBS直接推流功能，所有第三方推流工具均为违规。

**解决步骤**：
1. 明确结论：抖音已不支持OBS直接推流（2023年起）
2. 合规方案：
   - 使用抖音直播伴侣（官方PC直播工具）
   - OBS虚拟摄像头 → 抖音直播伴侣（合规的画面传输方式）
3. 操作方法：
   - 在OBS中启动虚拟摄像头
   - 打开抖音直播伴侣
   - 在直播伴侣中选择"OBS Virtual Camera"作为摄像头
4. 切勿使用任何第三方OBS推流工具，有封号风险

**相关链接**：[推流配置](streaming-config.md)

## FAQ-021: 各平台直播保证金政策汇总

**问题**：不清楚各平台开播是否需要缴纳保证金。

**症状**：
- 被要求缴纳保证金但不确定是否必须
- 不清楚保证金是否可退还
- 各平台保证金金额不明确

**原因**：
各平台保证金政策不同，且会定期调整。

**解决步骤**：
1. 各平台保证金要求（2026年最新）：
   - **淘宝直播**：个人5000元（企业可免缴），可退还
   - **抖音直播带货**：500元保证金，可退还
   - **抖音企业认证**：600元/年（认证费，非保证金）
   - **小红书**：无保证金要求
   - **视频号**：无保证金要求
2. 注意事项：
   - 保证金通常在停止直播且无违规后可申请退还
   - 如果只是做内容直播（非带货），部分平台不需要保证金
   - 建议在各平台官方页面确认最新金额

**相关链接**：[鉴权与权限](auth.md)

## FAQ-022: 平台直播封禁或限流怎么处理

**问题**：直播间被平台警告、限流或封禁，不知道原因和解决办法。

**症状**：
- 直播间突然被中断
- 收到平台违规通知
- 直播间观众数异常下降（疑似限流）
- 无法创建新的直播间

**原因**：
- 使用非官方推流工具（如在抖音用OBS直推）
- 直播内容违反平台规定
- 画面质量过低被系统判定为异常
- 多次推流失败触发平台风控

**解决步骤**：
1. 查看平台通知，了解具体违规原因
2. 常见违规行为：
   - 使用第三方推流工具（抖音）
   - 画面长时间静止或黑屏
   - 内容涉及敏感话题
   - 推流不稳定频繁断连
3. 申诉流程：
   - 在平台创作者中心找到"申诉"入口
   - 提交说明材料
   - 等待平台审核（通常1-3个工作日）
4. 预防措施：
   - 始终使用平台官方认可的推流方式
   - 保持推流稳定性
   - 遵守各平台内容规范

**相关链接**：[鉴权与权限](auth.md)

## FAQ-023: 视频号PC直播和OBS推流有什么区别

**问题**：不确定该用PC微信直播还是OBS推流，两者有什么不同。

**症状**：
- 不知道两种方式的区别和适用场景
- 粉丝数在200-1000之间，不确定能用哪种

**原因**：
视频号提供多种直播方式，不同方式的门槛和功能不同。

**解决步骤**：
1. 三种方式对比：
   | 方式 | 粉丝要求 | 画质控制 | 适用场景 |
   |------|----------|----------|----------|
   | 手机直播 | 无门槛 | 低 | 简单直播 |
   | PC微信直播 | 200粉丝或注册7天 | 中 | 日常直播 |
   | OBS推流 | 1000粉丝 | 高 | 专业直播 |
2. PC微信直播：在PC版微信中直接开播，可选择窗口/摄像头
3. OBS推流：通过推流地址将OBS画面推送到视频号，画质和自由度最高
4. 建议：
   - 粉丝<200：先用手机直播
   - 200-1000粉丝：使用PC微信直播
   - 1000+粉丝：使用OBS推流获得最佳效果
