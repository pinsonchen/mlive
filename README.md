## 🔧 一键诊断工具

遇到推流问题？运行诊断脚本快速定位故障，脚本覆盖 **8 项**检测并直接给出 FAQ 建议链接：

| 检测项 | 内容 |
|--------|------|
| CHECK-01 | RTMP 端口 1935 连通性（各平台推流服务器） |
| CHECK-02 | 推流地址格式校验（正则匹配各平台规范） |
| CHECK-03 | 本地上行带宽估算（判断是否满足多平台推流需求） |
| CHECK-04 | OBS 配置文件解析（码率/编码模式/插件检查） |
| CHECK-05 | 系统 CPU/RAM 资源检查 |
| CHECK-06 | 平台服务器网络延迟（ping 测试） |
| CHECK-07 | 本地防火墙/出站端口封锁检测 |
| CHECK-08 | 各平台域名 DNS 解析检查 |

### 用法

```bash
# 基本运行（交互式彩色报告）
bash scripts/diagnose.sh

# 输出 JSON 格式报告
bash scripts/diagnose.sh --json

# 同时保存 JSON 报告到文件
bash scripts/diagnose.sh --output=report.json

# 校验推流地址格式（设置环境变量后运行）
RTMP_URL_TAOBAO="rtmp://xxx.alivecdn.com/live/your-key" \
RTMP_URL_XIAOHONGSHU="rtmp://push.xiaohongshu.com/live/your-key" \
bash scripts/diagnose.sh
```

| 平台 | 手机直播 | OBS推流 | 手机直播粉丝要求 | OBS推流粉丝要求 | 保证金 |
|------|----------|---------|------------------|-----------------|--------|
| 🛒 淘宝直播 | ✅ | ✅ | 1万淘宝粉或5万外站粉 | 1000+粉丝（达人） | 5000元/企业可免 |
| 💬 视频号直播 | ✅ | ✅ | 无门槛 | 1000粉丝 | 无 |

** OBS推流门槛以App内显示为准（存在不同说法）
*** 抖音2023年起已取消OBS推流，只能用直播伴侣
* 抖音企业认证600元/年，直播带货保证金500元

## 🛠️ 四种开播方案

### 方案一：OBS + Multi RTMP 插件（推荐）
- ✅ 画质最佳
- ✅ 资源占用最少
- ✅ 一次推流多平台同步
- ⚠️ 需要各平台RTMP推流权限

### 方案二：混合方案
- ✅ 兼顾画质和兼容性
- ✅ Multi RTMP + 虚拟摄像头组合
- ✅ 适合部分平台受限的情况

### 方案三：虚拟摄像头方案
- ✅ 最安全可靠
- ✅ 完全使用官方软件
- ✅ 不依赖平台推流权限
- ❌ 需要同时运行多个软件

### 方案四：全手机直播方案（NEW!）
- ✅ 零技术配置
- ✅ 无需电脑和OBS
- ✅ 各平台APP直接开播
- ✅ 适合移动场景和户外直播
- ✅ 通常无粉丝门槛

## 📋 重要更新（v2.0）

### 2026年2月24日重大更新：

#### 淘宝直播
- ⚠️ 新增**200粉丝要求**（OBS推流）
- 🔴 新增**"暂停"步骤**：开始→等待10秒→暂停→推流
- 🔴 码率限制更新为**2500kbps**

#### 视频号直播
- 🎯 区分三种直播方式（手机、Windows微信、OBS推流）
- 🔴 推流地址必须从助手动态获取
- 🔴 强调开播顺序：先OBS推流 → 再视频号开播

#### 小红书直播
- ⚠️ **注册时间满6个月**（新增）
- ⚠️ **近3个月原创笔记≥10篇**（新增）
- 🔴 手机端路径更新：我 → 菜单 → 创作中心

#### 抖音直播
- 推荐虚拟摄像头方案（安全可靠）
- 1000粉丝或企业认证才能获取RTMP权限

- CPU：Intel i7 8代 / AMD Ryzen 7 或以上
