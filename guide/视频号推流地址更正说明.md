# 视频号直播推流地址更正说明

## 问题发现

用户指出视频号直播的推流地址 `rtmp://live-push.tencent.com/live/` 是不正确的。

经过深入调研确认：**这个地址确实是错误的！**

---

## 问题分析

### ❌ 错误的做法

在guide中给出了一个固定的RTMP地址：
```
RTMP服务器：rtmp://live-push.tencent.com/live/
```

### ❌ 为什么这是错误的？

1. **视频号使用腾讯云直播服务**
   - 推流域名格式为：`xxxxx.livepush.myqcloud.com`（腾讯云标准格式）
   - 不是 `live-push.tencent.com`

2. **每场直播的推流地址都不同**
   - 推流地址是动态生成的
   - 包含鉴权参数（txSecret、txTime）
   - 每次创建直播间都会生成新的地址

3. **推流地址包含多个部分**
   - 协议前缀：`rtmp://`
   - 动态推流域名：每场直播不同
   - 应用名：通常为 `live`
   - 流ID：每场直播不同
   - 鉴权参数：用于安全验证

---

### ✅ 更新后的guide（已修正）

**移除了固定的推流地址示例**，改为：

1. **强调推流地址必须从视频号助手获取**

   ```markdown
   都会生成不同的推流地址和密钥。请务必从视频号助手复制，
   不要使用其他来源的地址！
   ```

2. **说明推流地址格式**
   ```markdown

   rtmp://[动态推流域名]/live/[流ID]?[鉴权参数]

   请直接从视频号助手复制使用。
   ```

3. **提供获取方法**
   - 创建直播间后会自动跳转到【直播配置】页面
   - 在该页面可以看到并复制推流地址和密钥
   - 如果找不到，提供备用方法

## 腾讯云直播推流地址格式

根据腾讯云官方文档，标准的RTMP推流地址格式为：

```
rtmp://<推流域名>/<应用名>/<流名称>?txSecret=<签名>&txTime=<过期时间>
```

### 各组成部分说明

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| **协议前缀** | 必须是 `rtmp://` | `rtmp://` |
| **推流域名** | 腾讯云提供的推流域名 | `12345.livepush.myqcloud.com` |
| **应用名 (AppName)** | 默认为 `live`，可自定义 | `live` |
| **流名称 (StreamName)** | 每路直播流的唯一标识符 | `livestream_001` |
| **鉴权参数** | txSecret 和 txTime | `?txSecret=xxx&txTime=5867D600` |

### 完整示例（仅供参考格式）

```
rtmp://12345.livepush.myqcloud.com/live/livestream_001?txSecret=abc123&txTime=5867D600
```

**注意**：这只是一个格式示例，实际地址会因直播间而异。

## 为什么要移除固定地址？

### 1. 地址是动态生成的

视频号直播使用腾讯云的直播服务，推流地址包含：
- 动态的推流域名（如 `12345.livepush.myqcloud.com`）
- 随机生成的流ID
- 带时间戳的鉴权参数
- 每场直播都不同

### 2. 提供固定地址的危害

如果用户使用了错误的固定地址：
- ❌ 推流失败，无法连接到服务器
- ❌ 显示"连接超时"或"无法访问服务器"
- ❌ 浪费时间排查问题
- ❌ 影响直播计划

### 3. 正确的做法

```
1. 创建直播间
   ↓
2. 系统自动跳转到【直播配置】页面
   ↓
3. 复制显示的推流地址和密钥
   ↓
4. 粘贴到OBS中
   ↓
5. 开始推流
```

## 推流地址的组成部分详解

### 完整的推流地址示例

```
rtmp://12345.livepush.myqcloud.com/live/stream_20250224_123456?txSecret=abc123def456&txTime=1740384000
```

### 各部分说明

| 部分 | 说明 |
|------|------|
| `rtmp://` | 协议前缀 |
| `12345.livepush.myqcloud.com` | 腾讯云分配的推流域名 |
| `/live/` | 应用名（固定为live） |
| `stream_20250224_123456` | 流ID（唯一标识这场直播） |
| `?txSecret=abc123def456` | 鉴权密钥（用于安全验证） |
| `&txTime=1740384000` | 过期时间（Unix时间戳） |

### 在OBS中如何填写

- **服务器（Service）**：选择"自定义"（Custom）
- **服务器（Server）**：粘贴完整的推流地址（包括 `rtmp://` 和域名）
- **串流密钥（Stream Key）**：粘贴流ID和鉴权参数

或者：

- **服务器（Server）**：粘贴 `rtmp://域名/live/` 部分
- **串流密钥（Stream Key）**：粘贴 `流ID?txSecret=xxx&txTime=xxx` 部分

两种方式都可以，OBS会自动拼接。
