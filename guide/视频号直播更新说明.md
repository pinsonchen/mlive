# 视频号直播操作流程更新说明

## 更新日期
2026年2月24日

## 更新原因

用户反馈视频号直播的开播操作可能不准确，经过深入调研发现确实存在多处需要更新的内容。

---

## 关键发现和更新

### 🔴 重要更新：开播顺序

#### 更新前（不准确）
旧guide没有明确说明开播顺序，可能导致：
- 用户先在视频号点击"开始直播"
- 然后才在OBS中开始推流
- **结果**：观众看到黑屏！

#### 更新后（正确）
明确说明了正确的开播顺序：

1. **第一步**：在OBS中点击【开始推流】
   - 确认显示绿灯常亮
   - 预览页面显示实时直播场景

2. **第二步**：返回视频号助手点击【开始直播】
   - 确认OBS推流正常后，再点击开始直播
   - 此时直播间正式向观众开放

**结束顺序**：
1. 第一步：在视频号助手点击【结束直播】
2. 第二步：在OBS中点击【停止推流】

**重要性**：🔴🔴🔴 必须按照这个顺序，否则观众会看到黑屏或异常！

### 🔴 重要更新：前提条件

#### 更新前
```
✅ 完成实名认证
✅ 微信账号状态正常
✅ 已开通视频号
```

#### 更新后
```
✅ 完成微信实名认证
✅ 完成视频号认证（推流直播必要条件）❗
✅ 个人账号：有效粉丝≥100人或完成新手任务
✅ 企业账号：完成企业认证并绑定微信支付商户号
✅ 网络上传速率≥10Mbps，延迟低于300ms
```

**关键变化**：
- 新增"完成视频号认证"要求（这是推流直播的必要条件）
- 明确个人账号需要100粉丝或完成新手任务
- 明确企业账号的额外要求
- 添加网络要求

### 🟡 重要更新：创建直播间步骤

#### 更新前（过于简单）
```
1. 点击【发起直播】按钮
2. 填写直播标题、描述等信息
3. 选择【直播软件推流】模式
4. 系统将显示推流服务器和串流密钥
```

#### 更新后（详细准确）
```
1. 正确路径：左侧菜单 → 【直播管理】→ 【直播间管理】
2. 点击【创建直播】或【发起直播】按钮
3. 填写直播基本信息：
   - 直播主题：建议12字以内
   - 直播分类：根据内容选择（2025年新增选项）
   - 封面图：1080×1260像素（6:7），≤1MB
   - 直播描述：简明扼要
4. 选择开播类型：
   - 正常直播：公开推荐
   - 测试直播：最多200人可见，不计入统计
5. 点击【创建】
```

**新增内容**：
- ✅ 明确了操作路径
- ✅ 详细的直播信息填写要求
- ✅ 封面图尺寸和格式要求
- ✅ 开播类型说明（正常直播 vs 测试直播）
- ✅ 2025年新增的直播分类

---

### 🟡 重要更新：获取推流地址的步骤

#### 更新前
```
系统将显示推流服务器和串流密钥
```

#### 更新后
```
创建成功后，系统会自动跳转至【直播配置】页面：
- 推流地址（RTMP格式）
- 推流密钥（每次不同）

如果看不到推流信息：
1. 在【直播间管理】中找到刚创建的直播间
2. 点击【直播配置】或【推流设置】
3. 即可看到推流地址和密钥
```

**新增**：
- ✅ 说明"自动跳转"到直播配置页面
- ✅ 提供找不到推流信息的解决方法
- ✅ 强调每次直播推流码都不同

### 🟢 新增：OBS推流参数设置

#### 更新前
没有详细的OBS参数说明

#### 更新后（新增）
```
横屏直播（16:9）：
- 基础分辨率：1920×1080 或 1280×720
- 输出分辨率：与基础分辨率保持一致
- 帧率（FPS）：30帧
- 比特率：4000-6000kbps

竖屏直播（9:16）：
- 基础分辨率：1080×1920 或 720×1280
- 输出分辨率：与基础分辨率保持一致
- 帧率（FPS）：30帧
- 比特率：3000-5000kbps
```

### 方法对比

| 步骤 | 更新前 | 更新后 |

| 2 | 扫码登录 | 强调：必须用已开通直播权限的账号 |

⚠️ 必须按照这个顺序！
如果先在视频号助手点击"开始直播"，OBS还未推流，
观众会看到黑屏！

### 2. 账号要求警告（新增）
```
⚠️ 重要：
必须使用已开通推流直播权限的微信账号扫码登录，
否则看不到直播相关选项！
```

### 3. 推流码重生成提示（新增）
```
💡 提示：
每创建一次直播间，推流地址和密钥都会更换，
无法重复使用！
```

### 4. 结束顺序提示（新增）
```
💡 提示：
必须先结束直播再断开推流，顺序错误可能导致问题！
```

## 测试模式说明（新增）

### 什么是测试直播？

- ✅ 仅指定部分观众可见（最多200人）
- ✅ 不会公开推荐
- ✅ 不计入最近直播场数
- ✅ 不纳入主播任务、小时榜单统计
- ✅ 无法生成直播回放
- ⚠️ 商品购买、礼物赠送等功能会正常扣费

**用途**：适合正式开播前的测试和调试
