# 多平台同步开播操作指南 - 交互式网站

这是一个交互式的多平台同步开播操作指南网站，帮助用户根据选择的平台获得个性化的操作指导。

## 功能特点

- 🎯 **智能平台选择**：支持淘宝、抖音、小红书、视频号四个平台
- 📊 **权限提示**：自动显示各平台的门槛和要求
- 🔄 **方案推荐**：根据平台选择自动推荐最适合的开播方案
- 📝 **详细指南**：图文并茂的操作步骤
- 🔌 **插件安装引导**：完整的OBS Multi RTMP插件安装教程

## 使用流程

### 第一步：选择平台
- 勾选您要同步开播的平台（可多选）
- 系统会自动显示各平台的要求和限制
- 查看警告信息，确认账号条件

### 第二步：选择方案
系统会根据您的平台选择推荐三种方案：

1. **方案一：OBS + Multi RTMP 插件**（推荐）
   - 适合所有平台都支持RTMP推流
   - 画质最佳，资源占用最少

2. **方案二：混合方案**
   - 适合部分平台不支持RTMP的情况
   - Multi RTMP + 虚拟摄像头组合

3. **方案三：虚拟摄像头方案**
   - 最安全可靠的方案
   - 完全使用官方软件

### 第三步：获取推流地址
针对每个选中的平台，提供详细的推流地址获取步骤：
- 准备工作说明
- 具体操作步骤
- 注意事项和提示

### 第四步：配置OBS
根据选择的方案，提供相应的OBS配置指导：
- Multi RTMP 插件配置
- 虚拟摄像头设置
- 各平台直播伴侣配置

### 第五步：开始直播
最后检查清单和启动步骤

## 常见问题

**Q: 为什么有些平台显示"RTMP受限"？**
A: 这些平台对普通用户的RTMP推流权限有限制，建议使用虚拟摄像头方案。

**Q: 我可以同时选择所有平台吗？**
A: 可以，但请确保您的电脑配置足够好（推荐16GB+内存），网络带宽充足（建议50Mbps+上行）。

**Q: 推流地址有效期是多久？**
A: 不同平台不同，大多数是单次有效或24小时有效，建议开播前重新获取。

**Q: 使用虚拟摄像头方案画质会下降吗？**
A: 轻微下降，但几乎可以忽略。虚拟摄像头方案的优势是完全使用官方软件，安全可靠。
