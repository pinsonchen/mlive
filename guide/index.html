安装插件（方法一：使用安装程序 - 推荐）

Windows系统（.exe安装程序）：

  1. 关闭OBS Studio（如果正在运行）
  2. 双击运行下载的 obs-multi-rtmp-0.7.3.1-windows-x64-Installer.exe
  3. 安装程序会自动检测OBS安装目录
  4. 点击"Install"开始安装
  5. 等待安装完成，点击"Finish"

macOS系统（.pkg安装程序）：

  1. 关闭OBS Studio（如果正在运行）
  2. 双击运行下载的 .pkg 文件
  3. 按照安装向导提示完成安装
  4. 输入管理员密码（如果需要）
✅ 使用安装程序最简单，自动安装到正确位置，强烈推荐！
3

安装插件（方法二：手动安装）

如果安装程序无法使用，可以手动安装：

Windows系统：

  1. 下载 obs-multi-rtmp-0.7.3.1-windows-x64.zip
  2. 解压压缩包到任意位置
  3. 复制解压后的文件夹到：C:\Program Files\obs-studio\plugins\
  4. 或复制到：%PROGRAMDATA%\obs-studio\plugins\

macOS系统：

  1. 下载并解压压缩包
  2. 打开Finder，按 Cmd+Shift+G
  3. 输入路径：~/Library/Application Support/obs-studio/plugins
  4. 将解压的文件夹复制到该位置

Linux系统：

  1. 解压压缩包：unzip obs-multi-rtmp-*.zip
  2. 复制到插件目录：cp -r obs-multi-rtmp ~/.config/obs-studio/plugins/
4

验证安装

  1. 重新启动OBS Studio
  2. 在菜单栏查看是否出现新选项：
    • Windows/Linux：菜单栏【工具】→ 【Multi RTMP设置】
    • macOS：菜单栏【OBS Studio】→ 【Settings】→ 【Multi RTMP】
  3. 或者在【设置】→ 【插件】选项卡中查看是否有 obs-multi-rtmp 条目
✅ 如果看到"Multi RTMP"相关选项，说明安装成功！
💡 插件位置：
  • Windows：C:\Program Files\obs-studio\plugins\obs-multi-rtmp
  • macOS：~/Library/Application Support/obs-studio/plugins/obs-multi-rtmp
  • Linux：~/.config/obs-studio/plugins/obs-multi-rtmp

❓ 常见问题与解决方法

找不到obs-plugins或plugins文件夹？

解决方法：

  1. 确保已安装OBS Studio（不是OBS Classic旧版本）
  2. 检查OBS安装目录：
    • Windows: C:\Program Files\obs-studio\
    • macOS: /Applications/OBS.app
  3. 如果还是找不到，使用安装程序版本会自动安装
安装后找不到"Multi RTMP"选项？

可能原因和解决方法：

  1. OBS版本不兼容：检查插件版本是否支持您的OBS版本
  2. 安装位置错误：确保安装到了正确的plugins目录
  3. 未重启OBS：安装后必须完全关闭并重新启动OBS
  4. 权限问题：Windows用户尝试以管理员权限运行OBS
  5. 文件缺失：检查插件文件夹是否包含.dll（Windows）或.dylib（macOS）文件
安装程序提示找不到OBS目录？

解决方法：

  1. 先安装OBS Studio，再安装插件
  2. 如果OBS安装到自定义位置，使用手动安装方法
  3. Windows用户：从OBS菜单 → 帮助 → 日志文件，查看OBS安装路径
插件导致OBS崩溃或无法启动？

紧急解决方法：

  1. 进入插件安装目录删除obs-multi-rtmp文件夹
  2. 重新启动OBS
  3. 下载与您OBS版本匹配的插件版本
  4. 更新OBS到最新版本
如何查看当前OBS版本？

查看方法：

  1. 打开OBS Studio
  2. 点击菜单【帮助】→ 【关于OBS】
  3. 查看版本号（如：32.0.1）
